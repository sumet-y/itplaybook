⚙ Sysprep

C:\Windows\System32\Sysprep\sysprep.exe

ใช้ OOBE และ Generalize เพื่อเตรียมเครื่องต้นแบบสำหรับนำ Image ไปใช้กับเครื่องปลายทาง

📄 Unattend

ใช้กำหนดค่าบางส่วนของ Windows Setup อัตโนมัติ เช่น Region, Computer Name และขั้นตอน Setup

C:\Windows\System32\Sysprep\unattend.xml

🔧 Deployment Checklist

  1. ตรวจ Windows Version / Edition
  2. Install Drivers และ Software
  3. ตั้ง Region / Time Zone / Keyboard
  4. ตรวจ Disk / Partition
  5. ตรวจ Security / Antivirus / EDR
  6. ทดสอบ Application
  7. Run Sysprep Generalize + OOBE
  8. Capture Image
  9. Deploy Target
  10. ตรวจ Name / IP / Domain / Applications

🚨 หลัง Deploy ต้องตรวจ

รายการตรวจ
IdentityComputer Name / Domain
NetworkIP / DNS / Gateway
WindowsActivation / Update
SecurityAV / EDR / Firewall
Applicationเปิดใช้งานได้จริง
