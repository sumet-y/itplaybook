🖼 Troubleshooting Flow

flowchart TD
A["Windows Problem"]-->B{"กระทบ User เดียวหรือหลายคน?"}
B-->|User เดียว|C["Profile / PC / Application"]
B-->|หลายคน|D["Network / Server / Policy"]
C-->E["Event Viewer / Services / Settings"]
D-->F["AD / DNS / DHCP / Server"]
E-->G["Fix + Verify"]
F-->G

🔧 Basic Checklist

  1. Reproduce ปัญหา
  2. ตรวจเวลาเกิดเหตุ
  3. ดู Event Viewer
  4. ตรวจ Network / DNS
  5. ตรวจ Service
  6. ตรวจ Update / Driver
  7. แก้ไขและทดสอบซ้ำ
  8. บันทึกวิธีแก้
