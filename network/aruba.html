Aruba / HPE Switch

VLAN, Tagged และ Untagged

🧠 Aruba VLAN Concept

บน Aruba/HPE รุ่นที่ใช้คำสั่งแบบ ProCurve มักใช้ untagged กับพอร์ตที่รับ VLAN แบบไม่มี Tag และ tagged กับพอร์ตที่ส่ง VLAN Tag

🖼 ตัวอย่าง

flowchart LR
PC["PC"]--"Untagged VLAN 10"-->SW["Aruba Switch"]
SW--"Tagged VLAN 10,20,30"-->AP["Access Point"]

🔎 Commands

show vlan
show vlan ports 1-24
show interfaces brief
show trunks
show mac-address

⚙ ตัวอย่าง VLAN

vlan 10
   name "OFFICE"
   untagged 1-10
   tagged 24
exit

vlan 20
   name "VOICE"
   tagged 24
exit

🧠 Quick Memory

Untagged = พอร์ตปลายทาง VLAN หลัก · Tagged = ส่งหลาย VLAN ผ่าน Link เดียว
