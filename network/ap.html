flowchart LR

CTRL-->GW["Gateway / Firewall"]

🔧 Checklist

  1. AP มีไฟหรือไม่
  2. PoE Port จ่ายไฟหรือไม่
  3. Switch Port อยู่ VLAN ถูกต้องหรือไม่
  4. DHCP ได้ IP หรือไม่
  5. AP ติดต่อ Controller/Cloud ได้หรือไม่
  6. Client ได้ SSID และ IP หรือไม่
  7. ตรวจ RSSI / SNR / Channel

🧠 Quick Memory

AP Problem → Power → Link → VLAN → DHCP → Controller → RF → Client
