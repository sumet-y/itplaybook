🧠 TCP vs UDP

TCP

มี Connection, Reliable, ตรวจสอบการส่งข้อมูล เหมาะกับ Web/SSH/SMB

UDP

ไม่สร้าง Connection, Overhead ต่ำ เหมาะกับ DNS, Voice และงานที่ต้องการความเร็ว

🧠 Quick Memory

IP = ไปเครื่องไหน · Port = ไปบริการอะไร · TCP = เน้นความถูกต้อง · UDP = เน้นความเร็ว
