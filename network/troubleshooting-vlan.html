🖼 VLAN Troubleshooting Flow

flowchart TD
A["Client ใช้งานไม่ได้"]-->B{"ได้ IP หรือไม่?"}
B-->|No|C["ตรวจ DHCP / VLAN / Port"]
B-->|Yes|D{"Ping Gateway?"}
D-->|No|E["ตรวจ Access VLAN / Trunk / Gateway"]
D-->|Yes|F{"ไป Network อื่นได้?"}
F-->|No|G["ตรวจ Routing / Firewall"]
F-->|Yes|H["ตรวจ DNS / Application"]
