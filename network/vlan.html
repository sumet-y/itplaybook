🏷️ VLAN

Virtual Local Area Network

🧠 VLAN คืออะไร?

VLAN (Virtual Local Area Network) คือการแบ่ง Network เดียวออกเป็นหลาย Logical Network โดยไม่จำเป็นต้องแยก Switch ออกจากกัน

ตัวอย่างเช่น บริษัทมี Network เดียว แต่ต้องการแยก Office, Production และ Guest ออกจากกัน

📋 ตัวอย่าง VLAN

VLAN ชื่อ Network ตัวอย่างอุปกรณ์
10 OFFICE 192.168.10.0/24 PC / Notebook
20 PRODUCTION 192.168.20.0/24 เครื่องจักร / PC
30 GUEST 192.168.30.0/24 Guest Wi-Fi
40 VOICE 192.168.40.0/24 IP Phone

🔀 Access vs Trunk

🔵 Access Port

ใช้เชื่อมต่อกับอุปกรณ์ปลายทาง ที่ต้องการ VLAN เดียว

  • PC
  • Printer
  • กล้อง CCTV
  • Server บางกรณี
1 Port → 1 VLAN

🟣 Trunk Port

ใช้ส่งข้อมูลหลาย VLAN ผ่าน Link เดียว

  • Switch ↔ Switch
  • Switch ↔ Router
  • Switch ↔ Firewall
  • Switch ↔ Access Point
1 Port → หลาย VLAN

⚙ Cisco Example

สร้าง VLAN


vlan 10
 name OFFICE

vlan 20
 name PRODUCTION

vlan 30
 name GUEST

Access Port


interface GigabitEthernet0/1

 switchport mode access
 switchport access vlan 10

Trunk Port


interface GigabitEthernet0/24

 switchport mode trunk
 switchport trunk allowed vlan 10,20,30

🟣 Aruba / HPE Example

Untagged


vlan 10
   untagged 1-10

Tagged


vlan 10
   tagged 24

vlan 20
   tagged 24

vlan 30
   tagged 24

🧠 Quick Memory

  • VLAN = แบ่ง Network ทาง Logical
  • Access = ปกติใช้กับอุปกรณ์ปลายทาง / VLAN เดียว
  • Trunk = ขนหลาย VLAN ผ่าน Link เดียว
  • Tagged = Frame มี VLAN Tag
  • Untagged = Frame ไม่มี VLAN Tag
  • Gateway = ใช้สำหรับออกไปยัง Network อื่น
