🧠 Incident Response คืออะไร?

กระบวนการจัดการเหตุการณ์ Security อย่างเป็นระบบ ตั้งแต่ตรวจพบจนถึงกู้คืนและป้องกันไม่ให้เกิดซ้ำ

🚨 ตัวอย่าง: User เปิด Phishing

flowchart TD
A["User แจ้งเปิด Link"]-->B["เก็บข้อมูลเหตุการณ์"]
B-->C["ตรวจ Account / Endpoint"]
C-->D{"มีสัญญาณถูก Compromise?"}
D-->|Yes|E["Contain: Disable/Reset/MFA"]
D-->|No|F["Monitor + User Guidance"]
E-->G["ตรวจ Mail / Endpoint / Logs"]
G-->H["Recover"]
H-->I["Document + Lessons Learned"]

🔧 First Response Checklist

  1. อย่าลบหลักฐานโดยไม่จำเป็น
  2. บันทึกเวลา User / เครื่อง / Account
  3. แยกเครื่องหรือ Account เมื่อมีเหตุผลเพียงพอ
  4. แจ้งผู้รับผิดชอบตาม Escalation
  5. เก็บ Logs / Screenshot / Event ที่เกี่ยวข้อง
  6. Reset Credential เมื่อจำเป็น
  7. ตรวจ Scope ว่ากระทบเครื่อง/ผู้ใช้อื่นหรือไม่
  8. กู้คืนและติดตามผล
  9. ทำ Incident Report
