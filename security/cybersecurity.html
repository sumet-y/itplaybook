🧠 หลักคิด

Security ไม่ใช่แค่ Antivirus แต่คือการลดโอกาสเกิดเหตุ ลดผลกระทบ และทำให้กู้ระบบกลับมาได้

🖼 Security Layers

flowchart TB
U["User"]-->ID["Identity / MFA"]
ID-->EP["Endpoint / EDR"]
EP-->NET["Network / Firewall"]
NET-->APP["Application"]
APP-->DATA["Data"]
DATA-->BACK["Backup / Recovery"]

⚠️ Threat ที่ควรรู้

Threatตัวอย่างแนวป้องกัน
Phishingลิงก์/ไฟล์ปลอมTraining + Email Security + MFA
MalwareโปรแกรมอันตรายEDR + Patch + Least Privilege
Ransomwareเข้ารหัสข้อมูลEDR + Segmentation + Offline/Immutable Backup
Credential Theftขโมยรหัสผ่านMFA + Strong Auth + Monitoring

🔧 IT Support Security Checklist

  1. Windows และ Software อัปเดต
  2. Antivirus/EDR ทำงานปกติ
  3. Firewall เปิดใช้งาน
  4. User ใช้สิทธิ์เท่าที่จำเป็น
  5. MFA สำหรับระบบสำคัญ
  6. Backup ตรวจสอบและทดสอบ Restore
  7. มี Asset Inventory
  8. มี Incident Contact / Escalation
